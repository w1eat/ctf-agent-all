# 外部知识库检索评估

评估对象：Des-CTF-Knowledge commit `03525c6104c6f9c9a8061f05c2d045ecc31428b2`，索引格式 v5；Windows 11 10.0.26200，Python 3.14，SQLite FTS5。快照含 1,279 个文档、11,414 个检索片段。运行 `uv run python -m tools.evaluate_knowledge` 可在本机复测。

`tools/evaluate_knowledge.py` 中人工标注了 30 组查询与预期文件，覆盖 SQL 注入、命令执行、上传、包含、SSRF、反序列化、SSTI、JWT、隐写、压缩包、音频、代码审计和工具速查。当前版本 Hit@5 为 **30/30**；另有 2 条含大量无关词及线索位于末尾的压力查询，Hit@5 为 **2/2**。3 条无关查询均返回空结果。此次复测首次查询平均约 **11.7 ms**，P95 约 **16.8 ms**；已缓存查询 P95 小于 **0.001 ms**。机器与快照版本都会写入评估输出。

这些标注围绕知识库明确收录的主题，且部分查询包含原文技术词或标题词；结果证明这批已知主题可检索，不能代表所有新题的召回率，也不能证明解题成功率提升。下一阶段应用真实赛题的题目描述、附件名和分析过程中的报错进行盲测，同时分别统计知识库中已有原题 WP 与未收录题。模型成本与最终 flag 验证仍需在独立的端到端比赛测试中记录。

Planetary 方法卡均标记为待验证。确定性编排测试采用保存的 Planetary trace 中出现的技术词构造脱敏 fixture，仅验证检索调用、trace 元数据和下一轮知识注入；不访问远端题目，也不把检索命中解释为解题成功。
